📶
Recomendado

Impressora WiFi

A impressora tem IP próprio na rede do restaurante. O servidor envia o job direto pela internet para o IP da impressora via TCP.

  • Sem PC intermediário na cozinha
  • IP fixo configurado uma vez só
  • Epson, Bematech, Elgin, Daruma com WiFi
  • Porta padrão 9100 (TCP raw)
  • Precisa de IP fixo ou redirecionamento de porta
🖥️
Windows / USB

Servidor Local

Um PC Windows na cozinha roda o servidor Rebeca. Ele faz polling no sistema e imprime via USB, serial ou rede local interna.

  • Impressoras USB, serial ou rede local
  • PC Windows fica na cozinha ligado
  • Baixe o .exe e configure em 2 minutos
  • Funciona mesmo sem IP fixo na impressora
  • Auto-inicia com o Windows
